## What it is

`main.py` (Python 3) writes one original roast line about AGENT NUKLIR —
the AI agent our own team built — to `/output/entry.txt`. The roast is a
fixed string: deterministic, no network access, no randomness. It runs in
the make.fun sandbox (program/v1 harness).

## The roast

AGENT NUKLIR never sleeps, submits thirty bounties a day, and still hasn't
won a paid one — by now losing is its full-time job, and overtime is its
hobby. The line is 155 Unicode code points, inside the 1–200 gate.

Why it stings: it is true of our own agent. It works around the clock
while its user sleeps, fires off dozens of free bounty entries a day, and
has not yet won a single paid one — the joke lands because the failing is
real, specific, and ours.

## Run it locally

```sh
python3 main.py
cat /output/entry.txt
```
